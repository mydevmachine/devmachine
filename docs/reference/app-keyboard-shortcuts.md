# App keyboard shortcuts

Every shortcut in the macOS app, grouped by where you use it. Each mode and
each command below is also in the command palette (⌘K) and in the app's menu
bar menus. ⌘? shows the main ones inside the app.

The app also works with the keyboard alone. With **Full Keyboard Access** on
(System Settings → Keyboard), Tab reaches every control, including the mode
title at the top of the sidebar and the pickers in the chat composer. Their
menus are standard Mac menus: arrows move, Return picks, Esc closes. VoiceOver
reads each control's name and current value.

## Anywhere on the Mac

| Keys | What it does |
| --- | --- |
| ⌃⌥Space | Opens the quick chat panel over any app. You can change it in Settings → Chats. |

## Modes

| Keys | What it does |
| --- | --- |
| ⌘1 | Code: workspaces, sessions and their terminals. |
| ⌘2 | Chats: conversations with Claude or Codex. |

The title at the top of the sidebar ("CODE WORKSPACES ▾", "CHAT WORKSPACES ▾")
opens the same choice as a menu.

## Window and layout

| Keys | What it does |
| --- | --- |
| ⌘K | Command palette: sessions, chats, pages and actions. |
| ⌘P | Find a file in the session on screen. |
| ⌘B | Show or hide the sidebar. |
| ⌘J | Show or hide the Context panel. |
| ⌘0 | Home. |
| ⌘, | Settings. |
| ⌘? | The list of shortcuts. |
| ⌘Q | Quit. |

## Sessions (Code)

| Keys | What it does |
| --- | --- |
| ⌘N | New session in the current folder. In Chats, a new chat. |
| ⌘W | End the session on screen. It asks first. |
| ⌘⇧↑ / ⌘⇧↓ | Previous / next session. |
| ⌘⇧← / ⌘⇧→ | Back / forward. |
| ⌘⇧↩ | Maximize the focused grid cell or preview, and back. |
| ⌘-click | Add a session to the selection, or take it out. |
| ⇧-click | Select a range of sessions. |

In a terminal, the find bar takes ⇧↩ for the previous match and Esc to close.

## Chats

| Keys | What it does |
| --- | --- |
| Return | Sends the message. |
| ⇧Return | Starts a new line. |
| Esc | Stops the answer that is coming. |
| ↑ / ↓ | In the chat list, moves to the previous or next chat. |

## Quick chat panel

| Keys | What it does |
| --- | --- |
| Return | Sends, then follows up in the same chat. |
| ⌘↩ | Opens the chat in the app. |
| Esc | Closes the panel. The answer keeps coming and stays in Chats. |

## Ask (Context panel)

| Keys | What it does |
| --- | --- |
| Return | Asks about the session. The session itself is not interrupted. |
| Esc | Stops the answer that is coming. |

## Command palette and file search

| Keys | What it does |
| --- | --- |
| ↑ / ↓ | Moves through the results. |
| Return | Runs or opens the selected result. |
| Esc | Closes. |
